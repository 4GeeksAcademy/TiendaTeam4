# Contexto para la IA

- Usa unicamente HTML5 y Tailwind CSS.
- No uses React, Vue, Next.js ni JavaScript complejo.
- Mantén el estilo visual en blanco roto, beige y negro, con una apariencia limpia y comercial.
- Conserva la navbar y el footer consistentes entre las paginas.
- No modifiques archivos ajenos a la tarea si no es necesario.
- Respeta la estructura de ramas y el flujo de trabajo del equipo.
