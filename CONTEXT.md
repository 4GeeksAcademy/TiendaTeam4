# Contexto para IA y coding agents

## Stack

- Usa únicamente HTML5 semántico y Tailwind CSS mediante CDN.
- No uses React, Vue, Next.js ni otros frameworks.
- Evita JavaScript complejo, salvo que el ejercicio lo requiera expresamente.
- No añadas dependencias nuevas.

## Diseño

- Mantén una estética limpia, comercial y moderna, con blanco roto, beige, negro y tonos neutros suaves.
- Diseña para distintos tamaños de pantalla.
- Mantén la consistencia visual entre todas las páginas.
- Evita estilos que rompan la identidad visual del proyecto.

## Componentes globales

- Mantén la navbar y el footer consistentes en todas las vistas.
- Si ya están aprobados, no los regeneres ni rediseñes sin necesidad.
- Reutiliza los patrones visuales existentes antes de crear otros.

## Reglas de edición

- Revisa el código existente antes de modificarlo.
- Limita los cambios a los archivos necesarios para la tarea actual.
- No elimines código existente sin una razón clara.
- Usa HTML semántico.
- Evita duplicaciones innecesarias.
- Respeta los cambios realizados por otros colaboradores.

## Git y trabajo en equipo

- No trabajes directamente en `main`; crea una rama para cada tarea.
- Usa commits claros y descriptivos y sube la rama a GitHub.
- Abre un Pull Request y completa la revisión antes de integrar los cambios en `main`.
